A pretrained ImageNet ResNet-18 classifies an image. A one-step FGSM attack and an iterative PGD attack then try to move it off its own prediction under the same L-infinity budget, and you compare what each one costs and achieves.

On the sample image the model calls it a Samoyed at 88.5% confidence. Under a budget of 5/255 per channel, FGSM makes it an Arctic fox and PGD makes it a lynx at essentially 100% confidence — an answer that is both wrong and more confident than the right one ever was.

Run it in Colab

Open the notebook in Colab →

Run all cells. There is nothing to install and nothing to clone: the preprocessing, both attacks, and the driver are written out in the notebook’s own cells, and Colab already ships PyTorch, torchvision, Pillow, and matplotlib. The only network fetches are the pretrained weights (~45 MB) and one sample image. A GPU is optional — the whole notebook runs in under a minute on CPU.

Read the cells top to bottom, then start changing them. The last cell lists the experiments worth running, including the one that matters: pushing epsilon down until the attack stops working. On the sample image it still works at about 0.3/255 — a change smaller than one step of an 8-bit pixel value.

Run it locally, with the interactive UI

The same code also drives a Gradio app with sliders and an in-app code tutorial:

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py

Source

File Role
attacks/fgsm.py FGSM, written to be read
attacks/pgd.py PGD, written to be read
core.py model, preprocessing, attack driver — no UI
notebook_cells.py notebook-only code: image loading, plotting, sweep
app.py Gradio interface; imports core, adds no algorithms
build_notebook.py generates the notebook from the files above
adversarial_image_demo.ipynb generated — do not hand-edit

Editing (instructor)

The modules are the single source of truth and the notebook is a build artifact, so the two can never drift. Change attacks/fgsm.py — or any marked region — and rebuild:

python3 build_notebook.py           # regenerate the notebook
python3 build_notebook.py --check   # fail if it is stale

build_notebook.py inlines the regions delimited by # --8<-- start: NAME and # --8<-- end: NAME. If you move code across those markers, rebuild. Same arrangement as the slide decks: source in, generated artifact out, artifact never hand-edited.

Scope

White-box, untargeted, and pointed at a local public model on images you supply. A classroom sandbox for understanding a mechanism — not tooling for anyone else’s system.
